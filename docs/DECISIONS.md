# Decisions D0-D18: where each one stands

The decisions were taken by the owner on 4 October 2026 and are recorded in full in
[history/HANDOFF.md](history/HANDOFF.md) section 2 (the options and tradeoffs behind them are in
[history/CONSOLIDATION_DECISIONS.md](history/CONSOLIDATION_DECISIONS.md)). This page is the current list: what each
decision says in one line, where it landed in the code, and what kind of proof exists.

Status words, checked against the tree this page was written for (the integration branch, with the branches named
under "Not in this tree yet" in [ARCHITECTURE.md](ARCHITECTURE.md) not yet merged):

- **implemented**: the code is here and offline tests cover it.
- **partly**: some of it is here; the rest is named.
- **not yet**: nothing in this tree does it.
- **live proof pending**: the offline tests use fakes, so only a person on a real machine can show it works. Every such
  item has steps in [LIVE_CHECKS.md](LIVE_CHECKS.md). "Implemented" never means "works live".

| # | Decision (short) | Status | Where it landed, and what is left |
|---|---|---|---|
| D0 | Merge, then rewrite module by module. Keep `glide/computer`, `glide/providers`, `glide/assistant`. | implemented | The three packages are kept; the older flat imports became `glide.computer.*`. New packages: `speech`, `memory`, `mcp`, `webhooks`. |
| D1 | One neutral `generate(GenerationRequest)` writer boundary over the provider chains. | implemented, one leftover | `computer/generation.py` (the request and result shapes), `providers/writer_client.py` (`ChainWriter`, which sends every request through the chains, so a switch stays a `SwitchEvent`). `chat_messages` and `spells_out_schema` are gone. `generation.AnthropicProvider` (which still calls `messages.create`) is unused; it is a candidate for deletion, and `tests/guards_writer-boundary.py` refuses an SDK client built from the process environment. |
| D2 | Adopt `RunControl` (checkpoint, dispatch, in_flight); `stop()` calls it; it composes with `abort_on`. | implemented; provider cancellation over TLS live proof pending | `computer/control.py`; `providers/chain.py` calls every provider through `RunControl.interruptible`; `providers/interrupt.py` closes the connection. Tests: `tests/test_control.py`, `test_cancel_*.py`, `test_input_abort.py`. Reasoning recorded in the `control.py` docstring. |
| D3 | Content recording is opt-in, default off; keep a scrubbed `failure` in `run.json`. | implemented | `computer/diagnostics.py`, `runner.RunConfig.record_content`, `glide computer --record-content`.
